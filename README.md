# 🏠 Bengaluru Real Estate Price Analysis Dashboard


An interactive Power BI dashboard that analyzes Bengaluru's real estate market, helping users explore pricing trends across locations, BHK types, and price segments through dynamic filters and drill-downs.

> 🚀 **Data Scale & Impact:** Built on **13,000+ property listings** across **300+ localities**, cleaned and modeled for segment-level pricing insights.

---

## ✨ Features

- 🎯 **Smart Price Segmentation:** Classifies listings into Budget, Mid-Range, Premium, and Ultra-Luxury segments
- 📊 **Multi-Page Analysis:** 5 report pages — Overview, Ribbon Chart, Box Plot, Tree Map, and Tree Decomposition
- 🧮 **Engineered Features:** Custom DAX/Power Query fields like `price_per_sqft`, `location_tier`, and `is_cramped`
- 🗺️ **Geo Visualization:** Price distribution mapped across Bengaluru using Bing Maps integration
- 🎛️ **Dynamic Filters:** Slicers for location, BHK, price range, and society type
